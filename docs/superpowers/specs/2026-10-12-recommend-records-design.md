# 推荐记录与中奖核对 — 设计说明

日期：2026-10-12
范围：推荐结果本地留档 + 列表回看 + 按官方规则核对中奖

## 一、目标

推荐号码生成后写入浏览器本地存储，用户可随时回看「我买过什么」，并在目标期开奖后直接对奖，得到各奖级注数与奖金。

## 二、已确认的决策

| # | 决策点 | 结论 |
|---|---|---|
| 1 | 存储与查看 | `localStorage` 持久化 + 新增「推荐记录」列表页 |
| 2 | 目标开奖日期 | 自动推算下一期开奖日（沿用 live.js 开奖日规则），只读展示 |
| 3 | 重复生成 | 全部追加（含换一批），上限 200 条，超出淘汰最旧；可删除单条 / 清空 |
| 4 | 浮动奖 | 固定奖合计金额；一、二等奖只列注数，标注「浮动奖，以官方公告为准」 |
| 5 | 大乐透奖池档位 | 默认 <8 亿基础档计算，核对页提供「奖池 ≥8 亿」开关，切换后重算 |
| 6 | 记录粒度 | **一次推荐 = 一条记录**（一次生成 5 注只存 1 条，5 注放在同一条记录内） |

## 四、数据模型

`localStorage['lotto-records']`：

```json
{
  "v": 1,
  "items": [
    {
      "id": "r1760000000000-4f2",
      "kind": "dlt",
      "kindName": "大乐透",
      "betType": "dantuo",
      "dtForm": "both",
      "bet": {
        "main": [10, 13, 17, 21, 24, 33, 35],
        "special": [3, 5, 7, 11],
        "dan": [10, 35], "tuo": [13, 17, 21, 24, 33],
        "sDan": [11], "sTuo": [3, 5, 7],
        "tickets": []
      },
      "at": 1760000000000,
      "recDate": "2026-10-12",
      "target": "2026-10-14",
      "combos": 30,
      "cost": 60,
      "text": "前区胆：10 35\n前区拖：13 17 21 24 33\n后区胆：11\n后区拖：03 05 07"
    }
  ]
}
```

- **记录粒度：一次推荐 = 一条记录**。一次生成 5 注单式只写 1 条记录，5 注全部放在同一条的 `bet.tickets` 数组里（列表页显示「单式 5 注 · ¥10」）；复式 / 胆拖一条记录即一张票。
- **去重**：写入时按 `kind | betType | dtForm | bet` 生成签名，已存在相同签名只刷新时间——重新打开同一个结果页不会重复记账，「换一批」号码变了才追加一条。
- `bet.main` / `bet.special` 统一存**完整号码池**（胆拖时 = 胆 + 拖），用于界面展示与命中高亮；`dan/tuo/sDan/sTuo` 仅胆拖有值，用于展开；`tickets` 仅单式有值（`[{main, special}]`）。
- `text` 沿用现有 `betNumbersText()` 的输出格式，保证复制与记录一致。
- 上限 200 条，超出淘汰最旧；`localStorage` 不可用（隐私模式）时降级为内存数组，静默不报错；解析失败或 `v` 不符则重置为空。

## 五、模块划分

| 文件 | 职责 |
|---|---|
| `js/prize.js`（新）`window.LP` | 纯函数对奖引擎：奖级表、投注展开、逐注判级、汇总。不碰 DOM |
| `js/records.js`（新）`window.LR` | 读写 `localStorage`：`add / list / remove / clear / count` |
| `js/live.js` | 新增 `nextDrawDate(kind, now)` 并导出，与既有 `lastDrawDate` 对称、共用 `DRAW_DAYS` |
| `js/app.js` | 生成后写记录（一次推荐 = 一条）；推荐面板入口；记录列表页；核对页 |
| `index.html` | 在 `crowd.js` 之后、`app.js` 之前引入 `prize.js`、`records.js` |
| `css/style.css` | 记录列表、核对页样式（沿用现有暗色卡片风格） |

### `js/prize.js` 接口

- `LP.RULES` — 奖级表（双色球 6 级、大乐透 7 级两档）
- `LP.kSubsets(arr, k)` — 完整枚举 k 元子集（`crowd.js` 里的带截断版本不适合对奖，需另写）
- `LP.expand(bet, cfg, betType, dtForm)` — 展开为单式注数组：
  - 单式：直接返回 `bet.tickets`（一次推荐的 N 注都在这里）
  - 复式：`C(main, mainCount) × C(special, specialCount)`
  - 胆拖：`C(tuo, mainCount − dan) × C(sTuo, specialCount − sDan)`，未设胆拖的区按复式展开
- `LP.levelOf(kind, mainHit, specHit)` — 返回奖级编号（0 = 未中奖）
- `LP.findDraw(kind, targetDate)` — 在 `LC.draws(kind)` 中按 `d === targetDate` 匹配；无匹配返回 `null`
- `LP.check(kind, bet, draw, opts)` — 返回 `{ bets, hit, levels: [{level, name, count, per, sum}], fixedTotal, floatCounts: {1: n, 2: m} }`；`hit` 为是否至少有一注中任意奖级；`opts.tier` 决定大乐透档位（`'lt8'` / `'ge8'`）

展开注数保护：`MAX_EXPAND = 50000`，超出时不展开，界面提示「组合过多，仅展示投注信息」。

## 六、界面

### 1. 入口

推荐面板「生成推荐号码」下方：`推荐记录（N）` 幽灵按钮（N 为条数，实时更新）。

### 2. 记录列表页（二级页，复用现有 openPage）

按时间倒序，每条一张卡：

- 头部：玩法 + 投注方式（如「大乐透 · 双区胆拖 2 胆 + 5 拖」/「双色球 · 单式 5 注」）、注数、金额
- 推荐日期 / 目标开奖日期 / 状态（`待开奖` 或 `已开奖`）
- 号码文本（多注换行，胆拖按 `红球胆 / 红球拖 / 蓝球胆 / 蓝球拖` 展示）
- 操作：`复制` `删除`；点卡片主体进入核对页
- 顶部 `清空全部`（二次确认）；空列表给出引导文案

### 3. 核对页（记录卡片点击进入）

沿用截图的信息结构，配色适配项目暗色主题：

1. 顶部横幅：中奖显示固定奖合计（如 `¥135 恭喜中奖！`）；未中奖显示灰底 `本注未中奖`
2. `超级大乐透 · 第 26115 期` + 开奖日期 + 投注方式（复式票 1 倍 · 合计 36 元）
3. 大乐透时：奖池档位开关（`奖池 <8亿` / `奖池 ≥8亿`），切换即时重算合计与奖级金额
4. 「开奖号码」卡片：主区与特别区球号（沿用 `.ball-main` / `.ball-special` 配色）
5. 「您的投注号码」：**按红球 / 蓝球（大乐透为前区 / 后区）分列展示**，命中的号码高亮：
   - 单式：`tickets` 每注一行，行内红球一组、蓝球一组，两组之间用分隔符区分；行尾标出这一注的奖级（未中奖标「未中奖」）
   - 复式：红球池一行、蓝球池一行
   - 胆拖：红球区（胆、拖分段标注）、蓝球区（胆、拖分段标注），仍按红 / 蓝分列
   - 高亮规则：该号出现在当期开奖号码中即高亮；未命中保持 `.ball-main` / `.ball-special` 底色并弱化
6. 「中奖详情」（**仅在中奖时出现**）：按奖级汇总，每行 `六等奖 2 注 ¥30`（注数 × 单注金额 = 小计），末行固定奖合计；一、二等奖只列注数并标注 `浮动奖，以官方公告为准`
7. **未中奖判定**：所有展开注均未命中任何奖级 → `hit = false`，归为「未中奖」——顶部横幅显示 `本注未中奖`，**不展示中奖详情区块**，只保留开奖号码与投注号码。只要有任意一注命中任一奖级，才展示中奖详情
8. 底部：`复制号码` / `删除该记录`

### 4. 目标期未开奖

`findDraw` 匹配不到对应期时，核对页显示 `待开奖（目标 2026-10-14）`，只展示投注号码与目标日期，不做判定，也不显示中奖/未中奖横幅。

## 七、边界与错误

| 情况 | 处理 |
|---|---|
| `localStorage` 不可用 | 降级内存数组，静默 |
| 数据损坏 / 版本不符 | 重置为空，不阻塞页面 |
| 目标期未开奖或数据缺失 | 显示「待开奖」，不判定 |
| 所有展开注均未命中奖级 | 归为「未中奖」，不展示中奖详情区块 |
| 展开注数 > 50000 | 不展开，提示组合过多 |
| 一、二等奖 | 只统计注数，标注浮动 |

## 八、验证方式

1. **对奖引擎单测**（node + vm 加载 `prize.js`，不依赖 DOM）：
   - 双色球六个奖级各构造一注，断言奖级与金额
   - 大乐透七个奖级各构造一注，断言两档金额
   - 一次推荐 5 注单式：断言展开 5 注、命中按注分别判级、汇总正确
   - 复式展开注数 = `C(m, k) × C(s, sk)`；胆拖展开注数 = `C(tuo, k−dan) × C(sTuo, sk−sDan)`
   - `findDraw` 命中 / 未命中
   - 全不中时 `hit === false`、`fixedTotal === 0`
2. **存储层单测**：`add` 后 `list` 有序、超过 200 条淘汰最旧、`remove`、`clear`、脏数据重置
3. **浏览器冒烟**：生成 5 注 → 确认只新增 1 条记录 → 列表显示「单式 5 注」→ 点开核对页（已开奖中奖 / 已开奖未中奖 / 未开奖三种）
